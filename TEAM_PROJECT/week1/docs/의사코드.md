# 개인 환경 의사코드

대상 구현: `assignment_env.py`의 `AssignmentEnv`와 `run_assignment.py`.
참고 팀의 XYZ 제어 환경 의사코드가 아니라, 개인 제출안인 작업 배정 환경의 의사코드이다.

## A. 환경 생성 (__init__)

```text
입력: 시나리오 폴더(config.yaml, target.stl), 적층 작업 목록
팀 코드의 검증기 모듈을 연결한다
설정과 로봇 3대의 base/home/반경/속도를 읽는다
작업이 비어 있거나, 좌표가 비정상 또는 구간 길이가 0이면 거부한다
작업이 수평 구간이고 층 높이 순서인지 확인한다
팀 검증 규칙으로 적층 높이와 작업 영역을 확인한다
좌표 크기 기준과 시간 크기 기준을 계산한다
행동 공간 = 로봇 선택 3개
관측 공간 = 길이 11×작업수+32의 실수 벡터
RESET을 호출한다
처음 home에서 대기하는 로봇들이 도달/충돌 규칙을 만족하는지 확인한다
```

## B. 초기화 (reset)

```text
난수 시드를 설정한다
기본 작업 목록을 복원한다
방향 무작위화 옵션이 켜져 있으면 시드에 따라 구간 시작/끝을 뒤집는다
각 로봇의 경로를 [0초, home 위치, W] 한 행으로 초기화한다
모든 작업의 배정 이력을 0으로 초기화한다
다음 작업 번호 = 0
makespan = 0
종료 여부 = False
관측 벡터와 진행 정보를 반환한다
```

## C. 선택한 로봇의 안전한 일정 후보 생성 (candidate)

```text
입력: 로봇 번호
다음 작업의 시작/끝이 선택한 로봇의 XY 도달 범위인지 확인한다
도달 불가능하면 실패 후보를 반환한다

아래층 작업의 가장 늦은 복귀 시각을 구한다
최초 출발 가능 시각 = max(선택 로봇의 마지막 시각, 아래층 복귀 완료 시각)
후보 출발 시각 집합 = {
    최초 출발 가능 시각,
    그 이후에 있는 기존 모든 경로의 절점 시각,
    max(최초 출발 가능 시각, 현재 makespan)
}

후보 출발 시각을 빠른 순서로 반복한다:
    기존 전체 경로를 복사한다
    필요한 경우 선택 로봇의 home 대기 구간을 추가한다
    home → 작업 시작점: T, 시간 = 거리 / 이동 속도
    작업 시작점 → 끝점: D, 시간 = 거리 / 적층 속도
    작업 끝점 → home: T, 시간 = 거리 / 이동 속도
    마지막 행은 W로 둔다
    전체 로봇 경로의 경로 규칙과 도달 범위를 검사한다
    전체 로봇 경로의 충돌을 팀 검사기로 검사한다
    모두 통과하면 이 후보 경로와 출발 시각을 반환한다

모든 시각이 실패하면 불가능 후보를 반환한다
```

## D. 한 단계 실행 (step)

```text
입력: action ∈ {0,1,2}
이미 종료되었거나 행동 범위를 벗어나면 사용 오류를 알린다
선택 로봇 = action + 1
선택 로봇에 대해 C의 후보 생성 절차를 실행한다

후보가 없으면:
    기존 경로는 변경하지 않는다
    종료 = True
    보상 = -2
    관측, 보상, terminated=True, truncated=False, 실패 이유를 반환한다

후보가 있으면:
    이전 makespan을 저장한다
    후보 경로를 현재 경로로 채택한다
    makespan = max(이전 makespan, 선택 로봇의 복귀 시각)
    이 작업의 로봇·출발·소요·복귀 시간을 배정 이력에 저장한다
    다음 작업 번호를 1 증가시킨다
    보상 = -(makespan - 이전 makespan) / time_scale
    모든 작업 배정이 끝났으면 종료=True, 보상에 1 추가
    새 관측, 보상, 종료 여부, truncated=False, 진행 정보를 반환한다
```

## E. 경로 내보내기와 최종 평가

```text
모든 작업을 배정했는지 확인한다 (미완료면 내보내기 거부)
기존 결과를 덮어쓰지 않을 새 입력 폴더를 만든다
원본 config.yaml, target.stl을 수정 없이 복사한다
각 로봇의 경로를 robot_id, time_s 순서로 CSV에 쓴다
한 번도 배정되지 않은 로봇은 전체 작업 시간 동안 W로 대기하게 쓴다
run_validation(입력 폴더, 평가 결과 폴더)을 실행한다
PASS/FAIL, makespan, 충돌, 도달 범위, 형상 결과를 저장한다
```

## F. 1주차 확인 실험

```text
같은 config/STL/작업 목록으로 다음 규칙을 각각 실행한다:
    single: 항상 로봇 1
    round_robin: 로봇 1→2→3→1 순환
    greedy: 세 로봇 후보 중 현재 makespan이 가장 작은 후보 선택
    random: 시드 42로 로봇 무작위 선택

각 규칙에 대해 RESET → 반복 STEP → EXPORT → RUN_VALIDATION
PASS 여부를 먼저 비교하고 통과한 경우의 makespan과 계획 계산 시간을 비교한다
이 결과를 학습된 PPO의 성과로 설명하지 않는다
```
