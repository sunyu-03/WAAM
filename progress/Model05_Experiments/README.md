# Model 05 | 대형 STL 형상의 작업 경로 생성 및 안전 여유 최적화



## 1. 실험 개요



**목적:** 350개 레이어로 구성된 대형 WAAM 형상에 적용 가능한 작업 경로를 생성하고, 형상 정확도 및 로봇 도달 가능성을 확보한다.



| 항목 | 내용 |
|---|---|
| 대상 | Model 05 |
| 로봇 수 | 3대 |
| 레이어 수 | 350 |
| 형상 높이 | 700mm |
| STL 삼각형 수 | 108,288 |
| 최종 경로 생성 후보 | Raster-only |
| Raster 간격 | 5.5mm |
| 작업 배정 | Reach-aware Greedy |



## 2. 경로 생성 방식 비교



### 실험 1 — Centerline의 한계



기존 Model 02·03에 적용했던 Centerline 알고리즘을 Model 05에 적용했다.



대표 레이어에서 사전 IoU가 33.63%로 나타나, 넓은 내부 영역의 미적층 문제가 확인되었다.



### 실험 2 — Hybrid Toolpath



Centerline과 Raster Infill을 결합하고 Raster 간격을 조절했다.



| 방식 | 대표 레이어 사전 IoU |
|---|---|
| Centerline 단독 | 33.63% |
| Hybrid 6mm | 89.57~90.18% |
| Hybrid 5mm | 92.44~92.98% |
| Hybrid 5.5mm | 91.07~91.38% |



5mm 간격에서 높은 형상 정확도를 확보했지만, 경로 간 중복 면적이 크게 나타났다.



### 실험 3 — 불필요한 Centerline 제거



Raster-only 5.5mm 방식과 Hybrid 5.5mm 방식을 비교했다.



두 방식은 대표 레이어 6개에서 동일한 사전 IoU를 기록했다.



한편 중복 면적 지표는 다음과 같이 변화했다.



| 방식 | 중복 면적 지표 |
|---|---:|
| Hybrid 5.5mm | 약 63.3% |
| Raster-only 5.5mm | 약 29.7% |



Raster-only 방식은 사전 형상 정확도를 유지하면서 중복 면적 지표를 약 33.6%p 줄였다.



*주의: 해당 중복 면적 지표는 Shapely 비드 면적 기반의 근삿값이며, 공식 Validator의 Overfill과는 다르다.*



## 3. 전체 350개 레이어 사전 형상 평가



최종 후보인 Raster-only 5.5mm 방식으로 모든 레이어의 사전 IoU를 검사했다.



| 평가 항목 | 결과 |
|---|---:|
| 검사 레이어 | 350 / 350 |
| 평균 IoU | 91.21% |
| 최소 IoU | 90.66% |
| 최대 IoU | 91.42% |
| IoU 90% 미만 | 0개 |



모든 레이어에서 사전 IoU 90% 이상을 기록했다. 다만 이 결과는 공식 Validator PASS를 의미하지 않는다.



## 4. 로봇 Reach 제약 개선



### 기존 Greedy 작업 배정



350개 레이어 모두 XY Reach 조건을 충족했지만, 도달 여유가 매우 작았다.



- 최소 도달 여유: 0.003mm

- 평균 최소 도달 여유: 2.047mm

- 최소 도달 여유 5mm 미만 레이어: 333개



### Reach-aware Greedy 도입



로봇 선택 시 5mm 이상의 도달 여유를 확보할 수 있는 로봇을 우선하도록 작업 배정 방식을 개선했다.



5mm 기준을 확보하지 못하는 경우에는 기본 Reach 조건을 적용하고 예외 발생 횟수를 기록하도록 구현했다.



### 최종 Planning 결과



| 항목 | 결과 |
|---|---:|
| 전체 레이어 | 350개 |
| 총 작업 경로 | 75,868개 |
| 5mm 여유 미충족 작업 | 0개 |
| 최소 배정 도달 여유 | 5.0015mm |
| 예상 Makespan | 409,508.19초 |
| Trajectory CSV 크기 | 62.08MB |



5mm 여유 기준은 본 실험에서 사용한 추가 제약이며 실제 로봇의 안전성 인증 기준은 아니다.



## 5. 공식 WAAM Validator 검증



**상태: 검증 진행 중**



현재 기존에 생성한 `trajectory.csv`를 사용하여 공식 Validator 검증을 진행하고 있다.



공식 검증 결과가 완료되면 다음 항목을 추가할 예정이다.



- Coverage 및 IoU

- Underfill / Overfill

- XY Reach 및 충돌 검증

- Makespan

- 최종 PASS / FAIL 및 실패 원인



## 6. 향후 과제



공식 Validator 검증 결과를 기준으로 경로 생성 알고리즘의 유효성을 판단한다.



형상 검증에 성공하면 Model 01에서 학습한 PPO 정책을 추가 학습 없이 적용하여 Greedy와 작업시간을 비교할 예정이다.



또한 대형 형상에서 반복적인 STL 슬라이싱과 경로 생성을 최소화하기 위해 중간 경로 데이터를 저장하고 재사용하는 구조를 검토한다.
