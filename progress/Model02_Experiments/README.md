\# WAAM Model 02 — 경로 생성 알고리즘 개발 기록



\## 1. 실험 목적



교수님이 제공한 Model 02의 STL 형상에 대해 적층 경로를 생성하고, 공식 WAAM Validator를 통해 형상 재현 정확도와 로봇 작업의 안전성을 검증한다.



이번 단계는 PPO 일반화 평가에 앞선 \*\*경로 생성 알고리즘 개발 실험\*\*이며, 작업 배정에는 Greedy 방식을 사용했다.



\## 2. 실험 결과



| 버전 | 주요 변경사항 | Coverage | IoU | 결과 |

|---|---|---:|---:|---|

| v3 | 음수 Buffer를 적용한 Raster 경로 | 5.03% | 4.90% | FAIL |

| v4 | Buffer 축소 제거 | 93.07% | 59.36% | FAIL |

| v5 | 경로 길이 분석 기능 추가 | 93.07% | 59.36% | FAIL |



\## 3. 문제 분석



\*\*첫 번째 문제 — 과도한 형상 축소\*\*



비드 폭 8mm를 고려해 형상 내부로 4mm 축소했으나, 얇은 영역이 대부분 사라지면서 Coverage가 약 5%에 머물렀다.



\*\*두 번째 문제 — 과적층(Overfill)\*\*



형상 축소를 제거한 결과 Coverage가 93.07%까지 증가했지만, Overfill이 56.80%, IoU가 59.36%로 나타나 공식 Validator를 통과하지 못했다.



\*\*세 번째 분석 — 경로 길이 분포\*\*



v5에서 경로 길이를 분석한 결과 레이어당 159개 경로 중 8mm 미만 경로는 1개였다. 따라서 짧은 경로만 제거하는 방식으로는 문제 해결이 어렵다고 판단했다.



\## 4. 현재 성과 및 한계



\- Model 02의 8개 레이어에 대한 시험용 경로 생성 완료

\- `trajectory.csv` 생성 성공

\- 로봇 도달 범위 검사 통과

\- 로봇 간 충돌 이벤트 0건

\- 과적층과 낮은 IoU로 인해 형상 검증 실패



\## 5. 다음 개발 방향



기존 Raster Infill의 한계를 개선하기 위해 얇은 벽의 중심선을 추출하는 Centerline Toolpath 방식을 검토한다.



생성된 경로의 Coverage, Overfill, IoU를 비교하고, Validator를 통과하는 경로 생성 방식을 확보한 뒤 PPO 기반 로봇 작업 할당으로 확장할 계획이다.
